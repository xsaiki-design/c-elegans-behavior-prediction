If this were an early-warning alarm

Both models get the same alarm budget: each raises an alarm on the same share of this worm's moments (its own riskiest ones, set above), so the question is which model puts its alarms in the right places. An alarm is a hit when a reversal starts within the next 5 s. Move the slider to trade missed reversals against false alarms.

Try the warning setting. Counting last-second alarms, the body model wins in most worms: the worm slows down just before it reverses, and speed shows that. Ask for 2–3 s of warning and the brain model wins in most worms, because its signal starts earlier.

Never seen before

For each worm, the model was trained on the other 39 and then run on this one. Every line on this page comes from a model that never saw this animal.

Brain versus body

The grey line uses only what the body shows: speed, head angle and time since the last reversal. The orange line adds 46 named neuron types. The gap between them is what the brain adds.

What to look for

AIB tends to climb in the seconds before a reversal. AVA spikes during reversals and winds down afterwards, which is why its level says more about the last reversal than the next one.
